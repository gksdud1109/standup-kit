# 주간보고 양식

이 파일은 사람이 고치는 설정이다. `~/.standup/weekly-template.md` 로 설치되며,
회사 양식이 바뀌면 여기만 고친다. weekly 커맨드가 이 형식 그대로 채운다.

## 대분류

`1.` `2.` 로 매기는 상위 묶음이다. 아래 매핑에 없는 레포는 가장 가까운 분류에 넣는다.

| 분류 | 해당 레포·작업 |
|---|---|
| OCB 운영 | ob-backend, 이벤트 운영(가입 이벤트·스탬프·미리주는), CS 대응 |
| 사내 서비스 | polycube-*, unse-coupang, admin, IaC, 사내 도구 |

## 형식

```
<지난주 주간업무 보고> (8월 10일 ~ 8월 15일)
::주요업무
1. OCB 운영
# 코빗 가입 이벤트
- CS 2건 대응
- 문서 작성 및 위키 업로드

# 쿠팡 스탬프
- 마이너스 스탬프 월말 상쇄 정산 배치 추가
  - 매월 1일 전달 가용스탬프에서 마이너스 스탬프 상쇄
  - 수동 트리거로 동작 검증, 단위 테스트 작성, 검증용 엔드포인트 제거
  - 배포 후 이상 없음

2. 사내 서비스
# admin < PID 통합
- PID 기능이 통합된 Admin 운영 환경 배포
- 쿠팡 정기 배치 스케줄 활성화 — EventBridge 재시도 최대 3회, 1시간 제한

::잔여 확인
- 신규 사용자 문의 규격에 맞는 답변 기능 admin 추가

<이번주 주간업무 보고> (8월 17일 ~ 8월 22일)
```

## 규칙

- `# ` 제목은 프로젝트·이벤트 단위. **한 주에 한 번만 등장한다.**
- 최상위 불릿은 그 주에 끝낸 일. 여러 날 걸친 작업은 **과정이 아니라 결과 한 줄**로 적는다.
- 하위 불릿은 그 일의 구성 요소나 검증 내용. 두 단계까지만 쓴다.
- `::잔여 확인` 은 아직 안 끝난 것. 없으면 절 자체를 빼다.
- 날짜 범위는 월요일 ~ 그 주 토요일로 적는다.
